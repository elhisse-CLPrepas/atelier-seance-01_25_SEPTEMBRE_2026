Bonjour à toutes et à tous,

Pour préparer la séance 01 du Challenge 100 Jours — Relance Automne 2026, je vous partage le fichier d’installation de VS Code pour Windows.

Voici les trois outils à préparer :

• VS Code : créer et modifier vos fichiers.
• Git : conserver l’historique de votre travail.
• GitHub : héberger vos projets en ligne et collaborer.

Suivez cette checklist dans l’ordre.

1. INSTALLER VS CODE

☐ Téléchargez le fichier .exe joint sur votre ordinateur.
☐ Double-cliquez dessus.
☐ Acceptez le contrat puis cliquez sur « Suivant ».
☐ Gardez le dossier d’installation proposé.
☐ Laissez « Ajouter au PATH » coché et cochez « Créer une icône sur le Bureau » si cette option apparaît.
☐ Cliquez sur « Installer » puis « Terminer ».
☐ Ouvrez VS Code.

Si le fichier joint ne fonctionne pas, téléchargez la version Windows « User Installer » depuis le site officiel :
https://code.visualstudio.com/download

2. INSTALLER GIT

☐ Ouvrez le lien officiel :
https://git-scm.com/install/windows

☐ Téléchargez l’installateur adapté à votre ordinateur : x64 pour la plupart des PC Intel ou AMD, ARM64 pour un PC Windows ARM.
☐ Ouvrez le fichier .exe téléchargé.
☐ Gardez les réglages proposés et cliquez sur « Next ».
☐ Si le choix de l’éditeur apparaît, choisissez « Visual Studio Code ».
☐ Cliquez sur « Install » puis « Finish ».
☐ Fermez et rouvrez VS Code.

Pour vérifier :
☐ Dans VS Code, ouvrez « Terminal » → « New Terminal ».
☐ Tapez : git --version
☐ Appuyez sur Entrée.

Si un numéro de version apparaît, Git est installé.

3. CRÉER VOTRE COMPTE GITHUB

☐ Ouvrez :
https://github.com/signup

☐ Suivez les étapes pour créer votre compte.
☐ Utilisez une adresse e-mail à laquelle vous avez accès.
☐ Choisissez un nom d’utilisateur simple et un mot de passe personnel.
☐ Effectuez la vérification demandée et confirmez votre adresse e-mail.
☐ Choisissez l’offre gratuite si un choix vous est proposé.
☐ Vérifiez que vous pouvez vous connecter à votre compte.

GitHub s’utilise dans votre navigateur. Aucun logiciel supplémentaire n’est nécessaire pour cette étape.

VÉRIFICATION FINALE

☐ VS Code s’ouvre.
☐ Git affiche son numéro de version.
☐ Mon compte GitHub est créé et accessible.

Lorsque vous avez terminé, répondez dans le groupe :
« Prêt : VS Code + Git + GitHub ».

En cas de difficulté, indiquez l’étape concernée et joignez une capture d’écran sans mot de passe ni code de vérification.
